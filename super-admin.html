📦 تصدير نسخة احتياطية لكافة المطاعم والحسابات

تنزيل ملف JSON شامل لجميع سجلات جدولي `restaurants` و `restaurant_users` في ضربة واحدة.

🏪 سحب وتحميل بيانات المطعم وقائمة الطعام

سحب معلومات المطعم، أو تحميل قائمة الطعام كاملة بصيغة JSON أو تصديرها كملف Excel.

🔄 استعادة نسخة احتياطية (Restore from JSON)

اختر ملف JSON لنسخة احتياطية تم تصديرها سابقاً. سيقوم النظام بقراءة الملف والتحقق منه وإرساله سحابياً إلى قاعدة البيانات (`upsert`).

⚠️ إعادة التعيين لقيم المصنع وتصفير البيانات التجريبية (Factory Reset)

يقوم هذا الخيار بمسح الطلبات والفواتير التجريبية وإعادة تهيئة بيانات المطعم وقائمة الأطباق والأقسام والمستخدمين إلى القيم النموذجية الافتراضية الجاهزة للتشغيل.
